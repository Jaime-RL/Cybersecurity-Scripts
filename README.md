# Python Fundamentals

Short Python exercises covering the basics: control flow, functions with docstrings, lists, dictionaries, string manipulation and input validation.

| File | Exercise | Concepts |
|---|---|---|
| `number_sign.py` | Classify a number as positive, negative or zero | `if/elif/else`, `try/except` for invalid input |
| `list_minimum.py` | Find the minimum of a list without `min()` | Loops, edge cases (empty list) |
| `even_numbers.py` | Extract the even numbers of a list | List comprehensions |
| `element_frequency.py` | Count occurrences of each element | Dictionaries as hash maps |
| `palindrome.py` | Check whether a phrase is a palindrome | String normalisation and reversal |
| `multiplication_table.py` | Multiplication table of a number | Functions returning lists, `enumerate` |
| `circle_area.py` | Area of a circle | `math` module, f-strings |
| `password_validator.py` | Validate a password against strength rules | `any()` with generators, string methods |

## Running

```bash
python palindrome.py
```

No dependencies beyond the Python 3 standard library.
